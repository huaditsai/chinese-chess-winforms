# Chinese Chess (中國象棋)

A Chinese chess (xiangqi) board for two players on one computer, written in WinForms in July 2012. It draws the board, sets up the pieces and checks each move against the rules: the horse's blocked leg (馬腳), the elephant's blocked eye and the river, the advisor and general staying inside the palace, and the cannon jumping over exactly one piece to capture.

**Status: archived historical project, no longer maintained.** It targets .NET Framework 4.0 and has not been built or tested since 2012.

## Notes

The code uses pinyin names such as `huitu` (繪圖), `chidiao` (吃掉) and `panduan` (判斷), and comments such as 「象 稍微改變」 ("elephant: slightly changed"). This suggests it was adapted from an online example, but the original source was not identified.
